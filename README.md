# Level 3: Load balancer

3 EC2 instances in AWS (`us-east-1`) behind an **Application Load Balancer (ALB)**, configured with an **Ansible role**.

> [!NOTE]
> This is level 3 of a 3-level tutorial. Start with the README on the `main` branch, which explains how everything works.
> Levels: `main` → `three-instances` → **`load-balancer`** (you are here).

> [!TIP]
> When you're done reading, do the exercise in [LAB.md](LAB.md).

## What's new compared to level 2

- An **ALB** sits in front of the 3 servers. You visit one address, and it sends each request to one of the servers.
- The Nginx setup is packaged as an **Ansible role** (`ansible/roles/nginx-html-templating`).
- Terraform also writes `ansible/group_vars/all.yml` with the ALB address and the servers' IPs.

## What gets created

- A VPC with 3 public subnets (`us-east-1a`, `b`, `c`)
- 3 EC2 instances (`a`, `b`, `c`), one per subnet
- An ALB that spreads HTTP traffic across the 3 instances
- An SSH key, saved as `ansible/<student_name>-ssh-key.pem`
- `ansible/inventory.ini` and `ansible/group_vars/all.yml`, generated by Terraform

## Folder structure

```
infra/                           -> Terraform code (run terraform here)
ansible/                         -> Ansible code (run ansible here)
  render-template.yaml           -> playbook that applies the role
  ping.yml                       -> calls the ALB and prints the servers' IPs
  roles/nginx-html-templating/   -> the role: installs Nginx and creates index.html from a template
  host_vars/                     -> one file per server (the "username" shown on its page)
```

## Getting started

### 1. Create the infrastructure

```bash
cd infra
terraform init
terraform apply -var student_name=yourname
```

> [!IMPORTANT]
> Use your own `student_name` (lowercase, no spaces). Everyone shares the same AWS account, so it must be unique.

### 2. Configure the servers with Ansible

> [!NOTE]
> Wait about a minute after `terraform apply` so the servers can finish booting.

```bash
cd ../ansible
ansible all -m ping                    # check that Ansible can reach the 3 servers
ansible-playbook render-template.yaml  # install Nginx and create each server's page
ansible-playbook ping.yml              # call the ALB and print the servers' IPs
```

### 3. Test the load balancer

```bash
curl http://$(terraform -chdir=../infra output -raw alb_dns)
```

Run it a few times. The answer changes between "Hello from Alberta / Bocahontas / Cocoon": the ALB sends each request to a different server.

### 4. Clean up

> [!CAUTION]
> Always destroy your infrastructure when you're done. Servers and load balancers cost money while they run.

```bash
cd ../infra
terraform destroy -var student_name=yourname
```
