# Level 2: Three instances

**3** servers in AWS (`us-east-1`), one in each availability zone, configured by **1** Ansible playbook.

> [!NOTE]
> This is level 2 of a 3-level tutorial. Start with the README on the `main` branch, which explains how everything works.
> Levels: `main` → **`three-instances`** (you are here) → `load-balancer`.

> [!TIP]
> When you're done reading, do the exercise in [LAB.md](LAB.md).

## What's new compared to level 1

- **3 servers instead of 1** (`a`, `b`, `c`), each in its own subnet and availability zone (`us-east-1a`, `b`, `c`).
  If one zone has a problem, the other servers keep running.
- **Variables per server**: `ansible/host_vars/a.yml`, `b.yml` and `c.yml` each set a different `username`.
- **A template** for the web page: `ansible/templates/index.html.j2`. Ansible replaces `{{ username }}` with each server's value,
  so the same playbook creates 3 different pages: "Hello from Alberta / Bocahontas / Cocoon's website!".

## Folder structure

```
infra/                       -> Terraform code (run terraform here)
ansible/                     -> Ansible code (run ansible here)
  ansible.cfg                -> Ansible settings (which inventory to use, SSH options)
  inventory.ini              -> generated by Terraform
  playbook.yml               -> installs Nginx and creates the page from the template
  host_vars/                 -> one file per server (a.yml, b.yml, c.yml)
  templates/index.html.j2    -> the web page template
```

## Getting started

### 1. Create the infrastructure

```bash
cd infra
terraform init
terraform apply -var student_name=yourname
```

> [!IMPORTANT]
> Use your own `student_name` (lowercase, no spaces). Everyone shares the same AWS account, so it must be unique.

### 2. Configure the servers with Ansible

> [!NOTE]
> Wait about a minute after `terraform apply` so the servers can finish booting.

```bash
cd ../ansible
ansible all -m ping            # check that Ansible can reach the 3 servers
ansible-playbook playbook.yml  # install Nginx and create the pages
```

### 3. Check the result

```bash
terraform -chdir=../infra output public_ip
curl http://<one_of_the_ips>
```

Each server answers with its own page.

### 4. Clean up

> [!CAUTION]
> Always destroy your infrastructure when you're done. Servers cost money while they run.

```bash
cd ../infra
terraform destroy -var student_name=yourname
```
