# Terraform + Ansible flow: tutorial

Learn the **Infrastructure as Code** flow on AWS:

1. **Terraform** creates the servers
2. **Ansible** installs and configures the software on them

Everything runs in **`us-east-1`**.

## The learning path

The tutorial has 3 levels, one per branch. Each level has its own README and a lab (`LAB.md`).

| Level | Branch | What gets created | Lab |
|---|---|---|---|
| 1 · Easy | `single-instance` | 1 server with Nginx | Put a maintenance page online |
| 2 · Medium | **`main`** (you are here) | 3 servers with Nginx | Deploy a Node.js app on the 3 servers |
| 3 · Hard | `load-balancer` | 3 servers behind a load balancer | Show which server answered and test what happens when one goes down |

> [!TIP]
> **The goal is level 2 (this branch).** Start with level 1 if you're new to Terraform and Ansible, and try level 3 as a bonus.

To switch level:

```bash
git checkout single-instance   # level 1
git checkout main              # level 2
git checkout load-balancer     # level 3
```

> [!WARNING]
> Always run `terraform destroy` **before** switching branches. Otherwise your servers keep running (and costing money), and Terraform on the new branch won't know about them.

## How it works

```
 ┌─────────────┐  creates   ┌──────────────────┐
 │  Terraform  │ ─────────► │   AWS servers    │
 │  (infra/)   │            └──────────────────┘
 │             │  writes    ┌──────────────────┐   used by   ┌─────────────┐   configures (SSH)
 │             │ ─────────► │ inventory.ini    │ ──────────► │   Ansible   │ ──────────► servers
 └─────────────┘            │ + SSH key (.pem) │             │  (ansible/) │
                            └──────────────────┘             └─────────────┘
```

### 1. Terraform creates the infrastructure (`infra/`)

| File | What it does |
|---|---|
| `providers.tf` | Tells Terraform to use AWS, in `us-east-1` |
| `variables.tf` | The settings you can change: `student_name`, instance type, network ranges… |
| `main.tf` | The resources: network (VPC, subnets, internet gateway), firewall (security group), SSH key and servers |
| `outputs.tf` | What Terraform prints at the end, like the servers' public IPs |

### 2. Terraform hands over to Ansible

Ansible needs 2 things to connect to the servers: their **IP addresses** and an **SSH key**.
You don't have to copy them by hand. At the end of `main.tf`, Terraform writes them into the `ansible/` folder:

- `ansible/<student_name>-ssh-key.pem`: the private SSH key
- `ansible/inventory.ini`: the list of servers, with their IP and the key to use

```ini
[web]
a ansible_host=3.238.143.23 ansible_user=ec2-user ansible_ssh_private_key_file=./maria-ssh-key.pem
b ansible_host=98.81.250.21 ansible_user=ec2-user ansible_ssh_private_key_file=./maria-ssh-key.pem
c ansible_host=34.204.49.111 ansible_user=ec2-user ansible_ssh_private_key_file=./maria-ssh-key.pem
```

### 3. Ansible configures the servers (`ansible/`)

| File | What it does |
|---|---|
| `ansible.cfg` | Ansible settings: use `inventory.ini`, and only use our `.pem` key for SSH |
| `inventory.ini` | The servers (generated by Terraform). They are in the group `web` |
| `playbook.yml` | The tasks to run on the servers: install Nginx, start it, create the web page |
| `host_vars/a.yml`, `b.yml`, `c.yml` | Variables for one server only. Here: the `username` shown on its page |
| `templates/index.html.j2` | The web page. `{{ username }}` is replaced with each server's value |

> [!NOTE]
> Because each server has its own `username`, the same playbook creates 3 different pages: "Hello from Alberta / Bocahontas / Cocoon's website!".

## Before you start

You need:
- [Terraform](https://developer.hashicorp.com/terraform/install)
- [Ansible](https://docs.ansible.com/ansible/latest/installation_guide/index.html)
- AWS credentials. Check with `aws sts get-caller-identity`.

> [!IMPORTANT]
> Every level asks for a **`student_name`** (lowercase, no spaces, e.g. `maria`). Everyone shares the same AWS account,
> so your name goes on your resources to keep them separate from your classmates'.

## Level 2: step by step

### 1. Create the infrastructure

```bash
cd infra
terraform init
terraform plan  -var student_name=yourname   # preview what will be created
terraform apply -var student_name=yourname
```

When it finishes, Terraform prints the public IP of each server. Open `ansible/inventory.ini` to see what Terraform wrote.

### 2. Configure the servers with Ansible

> [!NOTE]
> Wait about a minute after `terraform apply` so the servers can finish booting.

```bash
cd ../ansible
ansible all -m ping            # check that Ansible can reach the 3 servers
ansible-playbook playbook.yml  # install Nginx and create the pages
```

### 3. Check the result

```bash
terraform -chdir=../infra output public_ip
curl http://<one_of_the_ips>
```

Each server answers with its own page.

### 4. Clean up

> [!CAUTION]
> Always destroy your infrastructure when you're done. Servers cost money while they run.

```bash
cd ../infra
terraform destroy -var student_name=yourname
```
